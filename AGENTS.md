# Agents

This repository is the PDS 1.26 6502 assembler shared by Super Robin Hood and Magician. Read the skill that matches the task before editing `pds6502.py` or a game's loader.

| Skill | When |
| --- | --- |
| [pds6502-scope](.cursor/skills/pds6502-scope/SKILL.md) | Deciding whether a source tree belongs here |
| [pds6502-dialect](.cursor/skills/pds6502-dialect/SKILL.md) | Selectors, `stop_at_end`, addressing |
| [pds6502-rebuild](.cursor/skills/pds6502-rebuild/SKILL.md) | Rebuilding either game and judging the result |

`README.md` is the human overview. `docs/manuals/The_PDS_6502_Manual.md` is the language. The module docstring at the top of `pds6502.py` is the measured dialect.
